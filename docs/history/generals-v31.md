# v3.1 장수 확충 메모 (135명 추가, 총 184명)

- 인물은 정사 『삼국지』·『후한서』와 소설 『삼국지연의』에 공통으로 나오는 공용 인물이다.
- **능력치(통솔·무력·지력·정치·매력)와 성향은 이 프로젝트가 직접 정한 값**이며, 상용 게임 수치를 옮기지 않았다. 성향은 원형(충직·야심·탐욕·자존심·무난·신중·용맹)에 id 기반 고정 흔들림(±8)을 더해 만든다 (`tools/data/roster_v31.py`).
- 생년은 정사 기준 대략값이다. 다음은 **추정**: 여영기(가공 인물, 연의계 전승), 주창(연의 인물), 학맹·성렴·조성·뇌박·장훈·양홍·장윤·위속·송헌·후성(생년 불명), 원소 휘하 다수(160 등 어림값).
- 197년 소속: 그해 이미 조조·여포·유비·손씨 진영에 있던 인물만 해당 세력에 넣었다. 원소·원술·유표·유장·마등·장로·장수 진영과 공손찬·이각 등은 한반도 사분천하 설정상 **재야 영웅**으로 둔다 (190년 시나리오에서 군주로 등장 예정).
- 손책(175~200)은 정사에서 197년 오의 실제 군주였으나, 이 게임의 시안 설정(군주 손권)을 따라 오의 장수·후계 1순위로 둔다 (게임적 해석).
- 등장 연도: 대략 16~20세 무렵. "모든 장수 등장" 옵션을 켜면 처음부터 성인(18세 이상)으로 등장한다 (가상 설정).
