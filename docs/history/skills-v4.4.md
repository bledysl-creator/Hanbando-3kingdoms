# v4.4 전술 고증 · 장수 특기 출처

> JIN이 준 두 책을 읽고 정리했다.
> - 『손자병법』 (김원중 옮김, epub): 13편 원문(한문)만 인용한다. 번역문은 옮기지 않는다.
> - 나관중 『삼국지』 (내 인생의 책 한 권, 26장 축약판, epub): **장 번호**와 줄거리만 쓴다. 본문은 옮기지 않는다.
>
> 축약판에 없는 일화는 **모종강본 회차**로 따로 적고 "(축약판에 없음)"이라고 표시한다. 회차는 일반에 알려진 모종강본 기준이며, 축약판으로 확인하지 못한 것이다.
> 정사 기록에서 가져온 것(고순 함진영)은 정사라고 적는다.

## 2. 일반 특기 (손자병법, 능력치별)

능력치 70 이상이면 생긴다. 높은 능력치 두 개(고유 특기가 있으면 하나)에서 가장 높은 단계 특기를 받는다.

| 능력치 | 90+ | 80+ | 70+ |
|---|---|---|---|
| 무력 | 질풍 疾風 — 其疾如風 (軍爭) | 선봉 先鋒 — 侵掠如火 (軍爭) | 분전 奮戰 — 死地則戰 (九地) |
| 통솔 | 상산 常山 — 率然 常山之蛇 (九地) | 부동 不動 — 不動如山 (軍爭) | 정정 正正 — 無邀正正之旗 (軍爭) |
| 지력 | 허실 虛實 — 避實而擊虛 (虛實) | 궤도 詭道 — 兵者詭道也 (計) | 간파 看破 — 佯北勿從 餌兵勿食 (軍爭) |
| 매력 | 동욕 同欲 (85+) — 上下同欲者勝 (謀攻) | | |
| 정치 | 인량 因糧 (85+) — 因糧於敵 / 以飽待飢 (作戰·軍爭) | | |

"지력이 높을수록 할 수 있는 능력이 다르게" — 전술 자체도 지력으로 열린다: 습량 50+, 의병 55+, 화공·도발 60·60+, 수공 75+. 지력 70대는 적 계략을 읽고(간파), 80대는 속이고(궤도), 90대는 적의 빈 곳을 친다(허실).

## 4. 수치는 우리 값

특기·전술 배율과 발동 확률은 모두 이 게임이 직접 정한 값이다 (`data/skills.json`, `src/core/config.ts`의 `BALANCE.tactical`·`BALANCE.skills`). 상용 게임의 특기 이름·수치를 가져오지 않았다. 특기 이름은 연의 일화와 손자병법 원문의 낱말에서 직접 골랐다.
