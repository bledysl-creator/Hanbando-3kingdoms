## 2. 일반 특기 (손자병법, 능력치별)

능력치 70 이상이면 생긴다. 높은 능력치 두 개(고유 특기가 있으면 하나)에서 가장 높은 단계 특기를 받는다.

| 능력치 | 90+ | 80+ | 70+ |
|---|---|---|---|
| 무력 | 질풍 疾風 — 其疾如風 (軍爭) | 선봉 先鋒 — 侵掠如火 (軍爭) | 분전 奮戰 — 死地則戰 (九地) |
| 통솔 | 상산 常山 — 率然 常山之蛇 (九地) | 부동 不動 — 不動如山 (軍爭) | 정정 正正 — 無邀正正之旗 (軍爭) |
| 지력 | 허실 虛實 — 避實而擊虛 (虛實) | 궤도 詭道 — 兵者詭道也 (計) | 간파 看破 — 佯北勿從 餌兵勿食 (軍爭) |
| 매력 | 동욕 同欲 (85+) — 上下同欲者勝 (謀攻) | | |
| 정치 | 인량 因糧 (85+) — 因糧於敵 / 以飽待飢 (作戰·軍爭) | | |

"지력이 높을수록 할 수 있는 능력이 다르게" — 전술 자체도 지력으로 열린다: 습량 50+, 의병 55+, 화공·도발 60·60+, 수공 75+. 지력 70대는 적 계략을 읽고(간파), 80대는 속이고(궤도), 90대는 적의 빈 곳을 친다(허실).

## 4. 수치는 우리 값

특기·전술 배율과 발동 확률은 모두 이 게임이 직접 정한 값이다 (`data/skills.json`, `src/core/config.ts`의 `BALANCE.tactical`·`BALANCE.skills`). 상용 게임의 특기 이름·수치를 가져오지 않았다. 특기 이름은 연의 일화와 손자병법 원문의 낱말에서 직접 골랐다.

## v4.4.1 고유 기술 35개 (전투당 한 번 쓰는 필살기)

JIN 요청: 고유 특기는 역사적 사실을 알려 주고, 그 일화를 전투에서 쓸 수 있는 기술로 만들어 일반 특기보다 확실히 세게. 예) 주유 「적벽」 → 큰 화공(대화공)으로 다량의 적을 죽임, 장합 「복병」 → 일반 복병보다 월등한 조건.

- 고유 특기(단계마다 발동하는 효과)는 그대로 두고, 그 위에 **고유 기술**을 얹었다. 5단계 전투 창에서 ⭐ 버튼으로 원하는 단계에 한 번 쓴다.
- 성공률 = 기본값 + (특기 능력치 − 80)%. 계략형은 적 장수 지력이 더 높으면 (차이 ÷ 2.5)%만큼 깎인다. 부장이면 ×0.85. 범위 30~92%. 실패하면 아군 사기 −6.
- 사기 효과(적 사기 −, 아군 사기 +)는 표의 값 × 0.5로 들어간다 (`BALANCE.skills.techMoraleMul`, 500판 검증 뒤 조정).
- AI도 같은 기술을 쓴다. 큰 피해 기술은 바로, 숨기·유인·계중계는 앞 단계에, 버티기 기술은 불리할 때.
- 일화와 출처는 위 고유 특기 표와 같다. 기술 이름의 한자는 연의 회목·고사성어에서 가져왔다(예: 水淹七軍, 火燒連營, 拔矢啖睛, 七縱七擒). 회목이 아닌 이름(席捲江東, 三日五百 등)은 일화를 줄인 우리 표현이다.
