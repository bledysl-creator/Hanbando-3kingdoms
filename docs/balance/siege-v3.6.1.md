# 포위 대응 밸런스 점검 (v3.6 → v3.6.1)

도구: `npx tsx tools/siege-balance.ts 100 best|hold` — 197년 사분천하, 도시 24곳, 160턴.
플레이어 세력을 위·여·촉·오 순서로 돌아가며(세력당 25판) AI가 대신 두고, 포위당하면
- **best**: 예상 결과(지킬 확률)가 가장 높은 대응을 고름 (모두 15% 미만이면 청야 철수) — 완벽한 플레이어의 상한
- **hold**: 항상 농성 — 아무것도 고르지 않는 플레이어

- AI가 플레이어 성을 노릴 때 승산을 1.25로 나눠 봄 (`siegeAiCaution`) — 농성·협공 대비. AI끼리 전투는 그대로

## 판단
- 화친 독주는 해소 (선택 1,087 → 306회, 지킴 87% → 65%)
- 협공이 가장 자주 최선이지만, 원군을 보낸 성이 비고 지면 원군도 잃는 위험이 있어 남겨 둠
- 출성 요격은 고를 일이 적지만, 장수 무력이 높아 고를 만할 때는 93% 지킴 → 상황형 선택지로 의도대로 동작
- 대응을 잘 고르는 플레이어가 유리한 것(통일 51판)은 전략 게임에서 의도한 방향. 농성만 하는 플레이어는 공평한 몫(25%)보다 약간 적은 19%
- 여포 생존: 플레이어 게임 10~19%로 목표(10%) 충족. 관전 모드는 즉시 전투라 이번 조정과 무관 (아래)
- 예상 결과(지킬 확률)와 실제의 차이는 3~7%p. 대응을 고른 뒤 같은 턴에 병력을 옮기거나 징병하면 실제가 달라진다
