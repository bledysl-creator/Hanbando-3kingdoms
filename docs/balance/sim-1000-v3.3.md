## v3.3에서 바꾼 것 (모두 플레이어·AI 공통 규칙)
1. **배수진**: 도시가 13% 이하만 남은 세력의 수비 +40%
2. **합종**: 도시 33% 이상을 가진 패자가 있으면, 나머지 세력은 패자가 아닌 상대와 휴전을 원하고 수락률 +25%
3. **어업**: 항구 도시는 계절마다 인구 1천 명당 곡식 20 (겨울 절반)
4. **AI 군량 계획**: 한 해 곡식(현재 + 예상 수확·어업 80%)으로 못 먹이면 징병하지 않고, 크게 모자라면 병력을 귀농시킴 (여포 군량 붕괴 원인 제거)
5. **고개 공격 보정** 0.85 → 0.75 (Game.md 4: 고개는 요충지)
6. 197 시나리오: 위·여 시작 휴전 1년 → 2년, 여포 시작 곡식 130,000 → 200,000

실험 비교(각 200판)는 작업 로그 참고: 고개만 0.75 → 여 생존 3%, 배수진 강화만 → 1%, 휴전 2년만 → 2%, 전부 + 합종 33% → 여 6.5%·촉 점유 42%.

## 남은 과제 (정직한 평가)
- 통일 비율이 목표(40%)보다 낮다. 합종이 패자를 견제하므로 장기전이 늘었다. 역사(83년 뒤 통일)에 더 가깝지만 게임 템포로는 느릴 수 있어, 플레이어 피드백을 보고 `hegemonShare`·`coalitionAccept`를 조정한다.
- 여포 생존 7.9%는 목표 10%에 조금 못 미친다. 역사상 1년 만에 멸망한 세력이라 억지로 올리지 않았다.
- 군현 지도(시·군 345곳)는 160턴 안에 통일이 거의 없다(20판 0판). 한 판이 매우 긴 모드.
