# 자가학습 110판 (v3.4)

- 도구: `npx tsx tools/selftrain.ts 6 10 160` — AI끼리 둔 판의 결과로 AI·밸런스 수치를 스스로 고치는 (1+1) 진화 전략
- 방식: 라운드마다 수치 하나(공격 기준·공세 집결·배수진·패자 기준·합종 수락률·반란 확률)를 조금 바꾸고, **같은 시드 10판**으로 바꾸기 전·후를 비교해 TEST_PLAN 목표에 가까워지면 채택
- 손실 = |통일률 − 55%| + max(0, 최대 점유 − 45%) + 2 × max(0, 10% − 최약 생존) + |평균 통일 턴 − 90| / 300
- 학습에 쓴 판: 처음 10판 + 5라운드 × 20판 = **110판**

## 결론 (정직한 평가)
- 학습 값은 학습 묶음(10판)에서는 좋아 보였지만, 새 200판에서는 **기존 값보다 나빴다**(촉 생존 36%→18%). 10판 비교는 운의 영향이 커서 과적합이 생겼다.
- 그래서 **기존 값을 유지**했다. 학습 도구는 남겨 두고, 다음에는 라운드당 판 수를 늘리거나(예: 50판) 밤새 돌리는 방식으로 쓴다.
- v3.4 전체(장수 301명·반란·장수 편제) 기준 관전 200판: 통일 53%(목표 40~70% ✅), 최대 점유 위 44%(✅), 평균 91턴(✅), 여포 생존 3.5%(❌), 반란·독립 판당 1.7회.
