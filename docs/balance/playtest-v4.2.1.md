## 고친 것
- 도시 패널: 내 도시는 수치를 **한 줄 요약**(병력·민심·농업·상업·성벽·훈련·날씨)으로 접고 명령을 바로 아래에. 누르면 펼침(기억). 재야 인재는 한 줄 힌트
- 내정: 농업·상업·성벽을 **맨 위 3칸 버튼**(현재 값 표시, 100이면 비활성)
- 군사: **출진·이동을 맨 위**로
- **🤖 맡기기**: 도시 패널(그 도시만)·오른쪽 아래(모든 도시). AI가 플레이어와 같은 명령 중 내정·인사(개발·구휼·진화·등용·포상·훈련·태수·군량 매입·말 기르기·수련·전선 건조)만 고름. 출진·이동·징병·귀농·편제·계략은 안 함. 금이 1,500(BALANCE.delegateGoldKeep) 아래면 금 드는 명령은 멈춤
- **다음 도시 ▶ (단축키 N)**: 행동이 남은 장수가 있는 도시로 차례로 이동
- 턴 알림 줄: 대기 장수 수·도시 수, 포위·포로 알림을 명령바 위에 한 줄로 모음
- 창 순서: 사건 카드 → 사신 → 포위 대응, 한 번에 하나씩
- 조사 교정: UI 문구에도 적용, 괄호 한자 뒤("촉(蜀)이")·숫자 뒤("190,268을", "3,000으로")도 처리
- 도시 제목 줄바꿈, 포위 대응 5가지를 한 줄에, 도움말 갱신, 버전 4.2.1

## 측정 (tools/playtest.ts 500판, 197 사분천하, 160턴, 플레이어 세력 4개를 돌아가며)
플레이어 자리에 "맡기기 → 나머지는 AI 판단"을 앉혀 셈.

| 항목 | 값 |
|---|---|
| 플레이어 턴 | 65,137 |
| 턴당 대기 장수 | 63.1명 (최대 230) |
| └ 맡기기가 처리 | 10.6명 (17%) |
| └ 직접 판단(출진·이동·징병 등) | 12.2명 |
| └ 할 일 없음 | 약 40명 |
| 턴당 사건 카드 / 사신 / 포위 | 1.42장 / 0.13건 / 0.08곳 |
| 창이 2개 이상 뜨는 턴 | 13.6% → 이제 순서대로 하나씩 |
| 플레이어 통일 | 촉 65/125 · 오 52/125 · 위 7/125 · 여 0/125 |

→ 맡기기 + 다음 도시로 한 턴에 직접 눌러야 하는 명령이 63번에서 12번 남짓(출진·이동·징병)으로 준다.

## 관전 500판 (밸런스 불변 확인)
변경 전·후 `npx tsx tools/simulate.ts 500 160` 결과가 **완전히 같음**: 통일 205판(41%, 오 105·위 50·촉 50), 평균 119턴, 여포 생존 70판(14%), 반란 1.61회/판. 맡기기는 플레이어만 쓰는 버튼이라 AI 밸런스에 영향 없음.
