# 0001. 기술 스택: React + TypeScript + Vite 웹앱, JSON 데이터, IndexedDB

- 날짜: 2026-11-25
- 상태: 확정 (Game.md 7, ChatGPT 기획안의 기술 요구사항과 일치)

## 배경
운영비 0원으로 시작하고, Claude와 대화하며 빠르게 만들 수 있어야 한다. 게임 화면의 대부분이 메뉴·표·지도다.

## 결정
- React 19 + TypeScript(strict) + Vite, GitHub Pages 배포
- 지도는 SVG (d3-delaunay로 세력 영역). 타일 수만 개 단계에서 Canvas/WebGL로 전환 검토
- 고정 데이터는 `data/*.json`, 세이브는 IndexedDB(idb-keyval) + JSON 내보내기
- 시뮬레이션 엔진(`src/core`)은 UI와 완전 분리, 시드 난수로 결정론 보장
- 클라우드 세이브·랭킹이 필요해지면 Supabase 무료 티어 (`SaveRepository` 교체)

## 대안
Godot 4(웹 내보내기 제약, Claude가 에디터 작업 불가), PixiJS(로직·저장 직접 구현), Phaser 단독(메뉴 UI 불편). 자세한 비교는 `research.md` 2장.
